How it works

One loop. Change, look, verify.

Most agents stop at "it should work now." Conn's agent sits next to a shell and a live browser, so it runs the app and checks the result before it says it's done.

  1. 01

    Edits the code

    Reads the file, makes the change, and the dev server in the terminal reloads on its own.

  2. 02

    Opens the page

    Navigates the built-in browser, clicks, types and reads the accessibility tree like a user would.

  3. 03

    Checks its work

    Takes a screenshot, measures, reads the console. If it's wrong, it goes around again.

FAQ

Questions

Do I need an API key?

No. Conn runs the agent CLI you already have, with its own login. If claude --version works in your terminal, it works in Conn.

How is this different from an editor agent?

Editor agents sit next to your code. Conn's agent sits next to a shell and a live browser, so it can run the app and look at the result before it says it's done.

Is Auto mode a sandbox?

No. It stops on a short list of dangerous commands, which is a convenience, not isolation. For real isolation, run the CLI in an OS-level sandbox.

What does it cost?

Nothing. Conn is open source under the MIT license.
