Questions

Do I need an API key?

No. Conn runs the agent CLI you already have, with its own login. If claude --version works in your terminal, it works in Conn.

How is this different from an editor agent?

Editor agents sit next to your code. Conn's agent sits next to a shell and a live browser, so it can run the app and look at the result before it says it's done.

Is Auto mode a sandbox?

No. It stops on a short list of dangerous commands, which is a convenience, not isolation. For real isolation, run the CLI in an OS-level sandbox.

What does it cost?

Nothing. Conn is open source under the MIT license.
