WHAT IT DOES

The agent sees the page you see.

Cursor puts an agent next to an editor. Conn puts one next to a shell and a live browser, with the browser tools already wired in. No MCP config, no restart, no setup step.

  • Point instead of describing

    Press Ctrl+Shift+E and click an element in the preview. It lands on the composer as a chip with its selector, its size and a screenshot of just that element.

    css: #go 129x39 at 48,261

  • Four permission modes

    Plan reads and changes nothing. Ask shows a card before each edit, command or page change. Auto stops on forced rm, sudo and history rewrites. Full bypass asks for nothing.

    Shift+Tab Plan Ask Auto Full

  • Dev servers open themselves

    The terminal watches its own output for a local URL. When Vite, Django or next dev prints one, a toast offers to load it in the preview. Say always once and it stops asking.

    Local: http://localhost:5173/

  • Sessions shared with claude --resume

    Claude chats are the transcripts in ~/.claude/projects. A chat you started in the terminal shows up in the rail, and one you start here shows up in claude --resume.

    ~/.claude/projects/

  • Skills and MCP servers, read off disk

    The pill above the composer lists every skill and server this folder has. Type / to filter skills. Add a server and it joins the running chat without a restart.

    .mcp.json ~/.claude.json plugins

  • Eight folders in one window

    Each folder keeps its own chats, shells and preview tabs. Switch away from one and its chats keep running. Run conn . on an open folder and its window comes forward.

    conn ~/code/shop

THE CONN COMMAND

Any shell can drive the same browser.

Every terminal Conn opens gets a loopback bridge and a tool token. A test script, a Makefile target or another agent can load the page, read it and click through it with the same ref handles the agent uses.

  • Bare ports, hostnames and full URLs all work with conn go.
  • A terminal agent driving the preview gets the same permission mode as the chat on screen.
  • Also exposed as an MCP server, so other tools can call it directly.
